Board size: 80 x 40 mm

2 layers, 1.6 mm FR-4, 1 oz copper, 80 x 40 mm, 2 mm corners, two M3 holes (3.2 mm, non-plated). Parts use about 653 mm² of 3200 mm² (20 %). Under 100 x 100 mm, the cheapest PCB tier. The ESP-01 module hangs off the bottom edge.

Edge plan

  • Left edge: USB-C (USB1).
  • Top edge: SW5 POWER, SW1 RESET, SW2 BOOT, SW3 IO 3V3|5V, SW4 UART|UPDI.
  • Right edge: H1 main header (pin 1 3V3 at the top).
  • Bottom edge: J3 ESP-Prog, J2 ESP-01 (module overhangs), J4 PROG 2.54, J5 UART2.

Order of work

  1. Draw the outline 80 x 40 mm with 2 mm corners and the M3 holes at (3.5, 3.5), (3.5, 36.5) mm (3.2 mm, non-plated).
  2. Update the PCB from the schematic. Check every footprint against its datasheet first (U2 QFN-24, U4/U5 SOT-23-6, USB1, J3 box header).
  3. Place block by block with the X / Y tables (origin top-left, Y down), ticking each part here.
  4. Draw one dashed rectangle per block on the Top Silkscreen layer with its title.
  5. Route USB D+/D- first, then power (wide traces), then signals. Pour GND on both layers.
  6. Silkscreen: H1 colour labels, POWER / RESET / BOOT / IO 3V3|5V / UART|UPDI, 5V IO!, OVERLOAD, AUTO-PROG (cap = ON), J5 pin names, ESP-01 outline.
  7. Run DRC, export Gerber, order (see the build guide).
