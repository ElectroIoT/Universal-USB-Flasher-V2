Setup in EasyEDA

1. Open your EasyEDA Pro project (one schematic, 8 sheets, one PCB).
2. Sheet names: Power, Target Power, USB+ESD, USB-UART, Auto-program, Target I/O, LEDs + Switches, Connectors.
3. Parts are placed by LCSC number (done). Set each Designator to the Ref in the tables below (rename U8 to U2).
4. Use net labels for every connection that leaves a sheet; the same name on both sheets. Names are case-sensitive (+3V3, not +3v3).
5. GND, +3V3 and +5V can be power flags; every other rail (VBUS_F, VIO, +3V3_T, +5V_T) is a normal net label.
6. Run the schematic check (ERC) after each sheet and fix every warning.
