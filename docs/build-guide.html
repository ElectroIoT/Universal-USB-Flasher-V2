Min hole / track0.3 mm via drill, 0.2 mm track (standard capability)

Quantity5 (minimum; spares are useful for the first bring-up)

Assembly decision

U2 CH342F is QFN-24 at 0.5 mm pitch. Two options:

① JLC SMT assembly of the top-side SMD parts. Check C2841530, C55266 and C111212 in the JLC parts library (extended parts carry a small fee). Solder the THT headers yourself.

② Hand build: hot-air station + paste for U2 (do it first), iron for everything else. Order a stencil if you have one board to try.

Step 4Order the parts (LCSC)

Set how many boards you build. Quantities add spares (0805 passives +5 per line, other parts +1), and LCSC may round some lines up to its own minimum. Tick each line as you add it to the cart.

Boards:
Lines marked "price not captured" are cheap passives or V1 parts; the total is a lower bound. Not on LCSC: nothing for the flasher itself (SJ1/SJ2 are copper pads). The pogo jig has its own list on the jig page.

Step 5Solder (per board)

Order matters: the hardest part first, the tall THT parts last. Pick the board you are working on; each board keeps its own ticks.

Step 6Bring-up tests and log (per board)

Type each measurement; the page checks it against the expected range. Do the no-power rows before plugging into USB. Use a USB power meter or a current-limited supply for the first power-up.

Step 7First flash

Two COM ports appear (CH342 dual serial). UART1 = H1 / J3 / J4 / ESP-01 socket; UART2 = J5.

Commands: esptool.py --port COMx chip_id · esptool.py --port COMx --baud 921600 write_flash 0x0 firmware.bin · UPDI: pymcuprog -t uart -u COMx -d attiny1614 ping. If an ESP refuses, hold BOOT, tap RESET, release BOOT.
